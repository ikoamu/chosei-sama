# 承認すると予約確定する

Status: ready-for-agent

## What to build

#02 で表示した候補から 1 つを選び、承認ボタンを押すと、状態を持たない Worker の予約確定 API が、主催者（自分）のカレンダーに予定を作って参加者へ招待を送る（**予約確定**）。承認は「人がボタンを押して API を呼ぶこと」そのもので、それ以前に書き込みは行わない。

タイトルは決まった形の既定値（例: 「打ち合わせ（自分・A・B）」）にし、編集欄は置かない。説明は空。単発は 1 件、定期は回数分の繰り返し予定として作る。

## Acceptance criteria

- [ ] 承認ボタンを押すまでカレンダーに何も書き込まれない
- [ ] 単発の予約確定で、主催者のカレンダーに予定ができ、参加者に招待が届く
- [ ] 定期の予約確定で、回数分の繰り返し予定ができる
- [ ] タイトルが既定の形で組み立てられている（組み立て部分に vitest のテストがある）
- [ ] 予約確定 API はセッション Cookie を検証し、未ログインなら 401
