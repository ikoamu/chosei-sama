# 手入力フォームから候補を表示する（Jev なし）

Status: ready-for-agent

## What to build

チャットに代わる最初の一本道（全層を貫く最小の経路）。Jev がなくても最後まで動く形にする（ADR 0003）。

参加者を今のピッカー（自分は常に含む）で選び、**調整条件**のフォームを手で埋めて送ると、状態を持たない Worker の候補提案 API が、依頼者本人の OAuth トークン（セッション Cookie の `refresh_token` からそのつど発行）で FreeBusy を照会し、単発または定期の候補を返して画面に表示する。トップ画面はこの時点でフォーム版に切り替える。

フォームの項目と規則:
- 必須: 所要時間、（定期なら）回数。埋めるまで送れない
- 既定あり: 検索期間（今日〜2週間後）、単発/定期（単発）、頻度（毎週）、曜日（平日）。既定値と分かる形で表示する
- 任意: 希望時間帯（ランキングを上げるだけで、候補は絞らない）

**空き可視性**: 読めない参加者が 1 人でもいれば候補を出さず、その人を名指しして中断し、フォームに戻す。

## Acceptance criteria

- [ ] ピッカー＋フォームから単発の候補が表示される
- [ ] 定期（頻度・回数・開始日）の候補が表示される
- [ ] 必須項目が空なら送れず、既定ありの項目は既定値で埋まっている
- [ ] 読めない参加者がいると名指しで中断し、候補は出ない
- [ ] 候補提案 API はセッション Cookie を検証し、未ログインなら 401
- [ ] フォームの値から scheduler への変換部分に vitest のテストがある

## Blocked by

None - can start immediately
