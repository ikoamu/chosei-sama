# Jev の接続確認（日本語・規約・API キー）

Status: ready-for-human

## What to build

TypeSafe AI の Jev を本アプリから使える状態にし、日本語の依頼文で**調整条件の下書き**が実用になるかを最初に確かめる（ADR 0003）。早期アクセスの申請・API キーの発行・規約の確認は人が行う。

- 早期アクセスを申請し、API キーを発行して Secrets（`TYPESAFE_API_KEY`）に登録する（dev / 本番とも）。リポジトリ・ログ・URL には残さない。
- TypeSafe の規約で、送信データの学習への利用・保持期間を確認する。社内に外部 AI ベンダーの審査があれば通す。
- SDK は使わず HTTP で直接、日本語の依頼文 3〜5 件を投げ、下書きのスキーマ（所要時間・検索期間の相対表現・単発/定期・頻度・回数・希望時間帯・曜日、各項目の確からしさ）で応答が返るかを見る。例:
  - 「隔週1h、来月開始、できれば午後」
  - 「30分、直近1週間で」
  - 「隔週6回」「来週のどこか」「何回か」

## Acceptance criteria

- [ ] `TYPESAFE_API_KEY` が dev / 本番の Secrets に登録されている
- [ ] 規約（学習への利用・保持期間）の確認結果が Comments に記録されている
- [ ] 日本語の依頼文 3〜5 件の応答（値・確からしさ・応答時間）が Comments に記録されている
- [ ] 日本語が実用にならない場合は、その旨を記録して #04 を止める判断をしている

## Blocked by

None - can start immediately

## Comments

### 2026-10-22 接続確認の結果（jev-1.14.0、`jev-latest` 指定）

API キーは発行済みで、dev の `.dev.vars` に登録済み。本番の Secrets（`wrangler secret put TYPESAFE_API_KEY`）と規約の確認は未完了。

Jev は値を自由に抜き出せない（Choice / Score / Noul のみ）ため、#04 の質問の組み立て（全項目を選択肢で選ばせ、計算はコード）で試した。1 回の呼び出しで 16 問をまとめて送信。

| 依頼文                         | 応答時間      | 主な答え（確からしさ）                                                     | 所見                                           |
| ------------------------------ | ------------- | -------------------------------------------------------------------------- | ---------------------------------------------- |
| 隔週1h、来月開始、できれば午後 | 450ms（初回） | 定期(1.00)・60分(1.00)・隔週(1.00)・来月(1.00)・午後(1.00)・回数なし(0.93) | 全項目正解。回数なし→必須なので要確認          |
| 30分、直近1週間で              | 207ms         | 30分(0.88)・7日以内(0.91)・起点=今週(0.69)・種類=不明(0.73)                | 起点が低信頼で要確認。種類は既定の単発で補える |
| 定例を隔週6回、毎回90分        | 205ms         | 定期(1.00)・90分(1.00)・隔週(0.83)・6回(0.99)                              | 全項目正解                                     |
| 来週のどこかで45分             | 200ms         | 45分(1.00)・来週(1.00)・単発(0.62)                                         | 単発が低信頼で要確認（値は正しい）             |
| 11/4以降で火曜か木曜、1時間    | 205ms         | 60分(1.00)・日付指定(1.00)・11月(0.98)・**日=なし(0.29)**                  | 「4日」を取り逃したが低信頼なので要確認に回る  |

- 日本語は実用レベル。誤りはいずれも確からしさが低く、要確認をすり抜けた誤りはなかった。
- 応答時間は 2 回目以降で約 200ms。
- **曜日（Noul）は言い回しに敏感。**「○曜日に開催したいと指定している」では「火曜か木曜」が 0.28 / 0.29 にとどまった。「文中で『○曜』または『○曜日』が希望する曜日として挙げられている」に変えると 0.96 / 0.98 になり、指定のない文では 0.03 前後。#04 では後者を使う。
