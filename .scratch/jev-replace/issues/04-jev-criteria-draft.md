# Jev による調整条件の下書き

Status: ready-for-agent

## What to build

#02 のフォームを、Jev が作る**調整条件の下書き**で事前に埋める（ADR 0003）。条件欄の自然文を下書き生成 API に送り、返ってきた下書きをフォームに入れて、ユーザーが確認・修正してから候補を出す。

- Jev へは SDK を使わず HTTP で直接、API キーは Secrets（`TYPESAFE_API_KEY`）から読む。
- 送るのは**条件欄の文章（メールアドレスらしき文字列は伏せる）と、今日の日付・タイムゾーンだけ**。参加者・FreeBusy の結果・候補は送らない。
- Jev は値を自由に抜き出せない（Choice / Score / Noul のみ）。数値・日付の計算も苦手（公式の jaggedness より）。そのため**すべての項目を選択肢から選ばせ、計算はコード（純粋関数）で行う**。条件欄の文章を `state` にし、次の質問を 1 回の呼び出しでまとめて送る:

  | 項目           | 型        | 選択肢                                                    |
  | -------------- | --------- | --------------------------------------------------------- |
  | 単発/定期      | Choice    | 単発・定期・不明                                          |
  | 所要時間       | Choice    | 15・30・45・60・90・120 分・該当なし                      |
  | 頻度           | Choice    | 毎週・隔週・4週ごと・該当なし                             |
  | 回数           | Choice    | 1〜12 回・該当なし                                        |
  | 期間の起点     | Choice    | 今日・今週・来週・今月・来月・○日以内・日付指定・該当なし |
  | ○日以内の日数  | Choice    | 3・7・14・30                                              |
  | 指定日の月・日 | Choice ×2 | 1〜12 月・1〜31 日・該当なし                              |
  | 希望時間帯     | Choice    | 午前・午後・夕方・該当なし（9–12 / 13–17 / 16–18 に変換） |
  | 曜日           | Noul ×7   | 各曜日の指定の有無（1 つもなければ既定の平日）            |

  「来週」＝次の月曜から始まる 1 週間。「該当なし」は選択肢の先頭に置かない（先頭に寄る癖があるため）。

- **要確認**: Choice の確からしさが閾値（全項目共通 0.8 から開始）未満の項目、Noul が 0.2〜0.8 の曜日、「該当なし」になった必須項目を強調表示する。既定ありの項目は、欠けていれば既定値で埋める（要確認にしない）。
- Jev が失敗したとき（タイムアウトは短め、例: 3 秒／エラー／スキーマに合わない応答）は、空の下書きを返して全項目を要確認にし、「自動で読み取れませんでした」と表示して手入力させる。

## Acceptance criteria

- [ ] 条件欄を書いて送ると、フォームが下書きで埋まる
- [ ] 確からしさが閾値未満の項目と、欠けた必須項目が要確認として強調される
- [ ] 相対的な日付表現から日付への変換に vitest のテストがある（月末・年またぎ・「来週」を含む）
- [ ] メールアドレスの伏せ字処理に vitest のテストがある
- [ ] Jev の応答を下書きに変換する部分に、Jev をモックにした vitest のテストがある（失敗・スキーマ違反を含む）
- [ ] Jev を止めた状態でも、手入力で候補まで進める
